# Password Security Analyzer

A beginner-friendly Python cybersecurity project that evaluates password strength and provides security recommendations.

## Features

- Checks minimum password length
- Checks for uppercase and lowercase letters
- Checks for numbers and special characters
- Detects predictable patterns such as `123`, `abc`, and `qwerty`
- Checks against a list of common passwords
- Gives a security score from 0 to 5
- Classifies passwords as Weak, Moderate, or Strong
- Provides recommendations for improving password security
- Does not store the actual password

## How to Run

1. Make sure Python 3 is installed.
2. Keep `password_analyzer.py` and `common_passwords.txt` in the same folder.
3. Open a terminal in the project folder.
4. Run:

```bash
python password_analyzer.py
